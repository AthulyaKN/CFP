# Contributing

Thank you for helping researchers find places to share their work!

## Add a new CFP (pull request)

1. Fork this repository.
2. Open `data/cfps.csv` and add one new row at the bottom. Fill every column you can.
3. Open `README.md` and add the same entry to the "Open calls" table, keeping the table sorted by deadline.
4. Commit with a message like `Add: <Event name> (deadline YYYY-MM-DD)`.
5. Open a pull request. A maintainer will review it, usually within a few days.

## Add a new CFP (no Git needed)

Use the **New CFP** issue template under the Issues tab and fill in the form. A maintainer will add it for you.

## Update or remove an entry

- Deadline extended or details changed: edit the row and mention the source in your pull request.
- Link broken or call closed: remove the row from the table and move it to `ARCHIVE.md`.

## Checklist before submitting

- [ ] The link goes to the official call page, not a third-party aggregator
- [ ] The deadline is in `YYYY-MM-DD` format and has not already passed
- [ ] The venue is legitimate (not predatory)
- [ ] The entry is not a duplicate
- [ ] Field and type use the existing tags where possible

## Code of conduct

Be respectful and constructive. Do not post spam, promotional content unrelated to a call for papers, or misleading information. Maintainers may remove entries that break these rules.
