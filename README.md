# Call for Papers (CFP) Hub

A community-maintained list of open calls for papers for conferences, workshops, journals, and special issues. The goal is simple: help researchers, students, and practitioners find places to submit their work, and help organizers reach the right audience.

> **Know a CFP that's missing?** Please add it. See [CONTRIBUTING.md](CONTRIBUTING.md) for the 2-minute guide.

## How to use this repository

- Browse the table below, or open [`data/cfps.csv`](data/cfps.csv) in any spreadsheet tool to filter and sort.
- Check the deadline and the official link before you plan a submission. Dates change, so always confirm on the official site.
- Star or watch the repository to get notified when new calls are added.

## Fields

Entries are tagged by field so they are easy to search. Common tags include: Computer Science, Engineering, Medicine & Health, Life Sciences, Physical Sciences, Social Sciences, Humanities, Education, Business & Management, Law, Arts & Design, Interdisciplinary. Feel free to propose new ones.

## Entry types

- **Conference**: in-person, online, or hybrid
- **Workshop**: usually co-located with a larger event
- **Journal**: regular submissions with a rolling or fixed deadline
- **Special issue**: themed journal issue with its own deadline
- **Book chapter**: edited volume calls

## Quality guidelines

To keep this list trustworthy, only add calls that:

1. Have an official website or call page that you link to.
2. Show clear submission dates and scope.
3. Are not predatory. Check the publisher or venue against resources such as [Think. Check. Submit.](https://thinkchecksubmit.org) and the [DOAJ](https://doaj.org) before submitting.
4. Do not charge unexplained fees or promise guaranteed acceptance.

## Contributing

Contributions of all sizes are welcome: new CFPs, deadline updates, broken-link fixes, and removal of expired entries. Read [CONTRIBUTING.md](CONTRIBUTING.md) to get started. You can also [open an issue](../../issues/new/choose) using the "New CFP" template if you are not comfortable with pull requests.

## Data format

All entries live in [`data/cfps.csv`](data/cfps.csv) with these columns:

| Column | Description |
|--------|-------------|
| `name` | Full name of the event or journal |
| `type` | Conference, Workshop, Journal, Special issue, Book chapter |
| `field` | Main field or topic |
| `location` | City, country, or "Online" |
| `deadline` | Submission deadline in `YYYY-MM-DD` (leave blank if rolling) |
| `event_date` | Event start date in `YYYY-MM-DD` (blank for journals) |
| `url` | Official CFP link |
| `added_by` | Your GitHub username |
